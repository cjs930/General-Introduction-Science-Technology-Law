# 【簽到及出缺席說明】

1. 本學期實際授課共12週(不含9/26中秋節、10/10國慶日、10/24光復節及12/26期末考週)，每週上午9:00開始，11:30下課。
2. 上午9:16(含)起至課程結束前完成簽到者，記為「遲到」；每週遲到按請假0.2週計算。
3. 請假累計達授課時數 1/5 (2.4週)，學期成績降一等第；達 1/4 (3週)，降二等第；達 1/3 (4週)，學期成績以X等第(或不及格)登錄。
4. 未經核准或准假期限屆滿後仍缺課者，以曠課論。曠課時數以請假時數5倍計算，曠課1週即相當於請假5週，學期成績以X等第(或不及格)登錄。
5. 經核准之公假、產假及歲時祭儀假(每學年限一日)，不計入上述請假時數及成績降等。
6. 紀錄代號：簽名=準時出席 / 綠色簽名=遲到 / 假=一般請假；曠=曠課；公=公假；產=產假；祭=歲時祭儀假。
